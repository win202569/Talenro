# Live completion supervisor — fixed offline diagnostic fixture

Authority: approved 2026-10-19 specification and Native implementation plan,
followed by explicit human approval for NEW five PS7 hosts/eight children and
conditional one fresh readonly final review. Not general runtime approval.

Only driver Prepare / RunOne for the five literal grants is supported. The
ordinary parent supervises one capture host per call; capture executes tests
in that same host, with no testing subprocess. Never dispatch the next grant
from a disk Outcome. Any unknown/nonexact/record failure stops the whole plan;
no automatic retry, repair, refund, reconstruction or second review.

All12 inputs are LF and frozen before the first core-red. Only session.psm1
and sinks.ps1 may change after exact core-red; only owned-step.ps1 after exact
owned-red. Baseline deliberately exhibits disk-positive advancement and failed
sink reuse, and the owned baseline retains an actual direct final receipt
retry. These are RED mechanisms, not accepted implementation behavior.

Each grant is independently authorized; acknowledgements do not cross hosts.
Only sequence A consumes an actual same-process acknowledgement. B has one
target despite two descriptors. C has a real closed output writer before its
one normal owned target; no fault callbacks or fake lifecycle setters.

Session and acknowledgement handles are private bounded reference identities,
not security tokens against malicious same-process reflection. Disk records,
views, JSON, hashes and Verified fields cannot resume a session. Fixed lexical
path ownership is not a hostile reparse-point security boundary. Failed sinks
are permanently isolated; release of an already-held handle is not a retry.

Single raw-byte consumer per redirected stream, parallel drains, exact held
Process cleanup only. No PID/name relookup, tree kill, Job/watchdog or process
inventory. Whole sequence140000ms; outer host150000ms (others120000), exit2000
and shared drains2000; file IO is not hard realtime. A killed supervisor does
not prove its children exited. Unknown is never success.

The transport shell is bootstrap coverage: static inspection and five actual
transports only, not independent dynamic proof of every exception boundary.
Late write/flush/close/host death are not all dynamically injected. Original
seam bytes and full ordered trace stay unchanged. CRLF is the literal combined
stdout template; comparison also permits CRLF→LF consistently, no filtering.

Raw evidence remains ignored; portable handoff is data only. SourceVerified,
LiveActionsPerformed, RuntimeApproved, FormalAcceptance, RealGateImplemented
remain false. No main merge, production capability, full-C12 acceptance or
change to old evidence/quotas; R2 and Minor2 deferred.
