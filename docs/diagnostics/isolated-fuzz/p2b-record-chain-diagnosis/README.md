# Record-chain scope diagnosis

Single-use, offline evidence gathering authorized by the user's approval of
`docs/superpowers/plans/2026-10-31-offline-record-chain-diagnosis.md`.
Native `driver.ps1 -Action RunOnce` launches one pinned diagnostic host only.
No writer operation, collector invocation, fault fixture, compilation, target
child, Session/Ack, runtime profile, review or repair is performed.

The observer loads immutable writer/collector definitions and reproduces only
the dynamic-module construction/call topology. A unique script-scope sentinel
tests state ownership. Command identity is measured with actual ScriptBlock
reference equality and module associations, not hashes of printed definitions.
JSONL records use a separate retained .NET stream/local observer state.

This is not a replacement writer-red, a regression test, or proof of the
historical first ErrorRecord. Original remaining repair allowances stay frozen.
The packet is single-use, including failed/unknown attempts. Do not replay it.
Only the parent classifies ordered stages after recording raw streams/exit.
