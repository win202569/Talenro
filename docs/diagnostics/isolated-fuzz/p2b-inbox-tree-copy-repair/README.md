Approved Native implementation, new five ordered ordinary PowerShell target hosts
(red, full, capacity, sequence, final) and one conditional independent readonly
reviewer only after all five exact outcomes. No retries. Unexpected results freeze
the remaining slots and review. The old 2/5 spent + 3 frozen and separate diagnostic
1/1 spent are unchanged. This is not formal or runtime acceptance.

Product begins as exact baseline 43067AD0. Only Copy-IBTree and the private
Get-IBTreeNode classifier may change after RED. Fixed codec and original 32 tests,
helpers, literals and descriptor fixture remain unchanged. New twelve focused
groups precede the original 32 groups in each full target, in the same host.
Expected output is fixed in advance: RED 3 lines/exit1, full 49 lines/44 PASS/exit0,
mutants 4 lines/exit1. No broader test, import, warmup or compilation host.

Each target has 120000ms execution, 2000ms owned exit and 2000ms concurrent
stream-drain bounds. Controller preconsumes every attempt, pins all inputs and
preserves separate raw streams/traces in the ignored session packet.
Prepare displays the full mapping inventory before freezing. Never rerun from
a fresh clone: original packets, machine dependencies and explicit authority
must be reconciled first. Portable summary records actual outcomes separately.

Authority flags remain false. Only internal owned trees are handled; no new
public input category, state restoration interface or real I/O is introduced.
